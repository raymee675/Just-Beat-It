**大事な決まり**
- Steam 版とは完全に切り離す。サイトに Steam 版のこと・リンクは一切載せない（Steam 版は筑駒の名前を出さないため）。
- 制作の名前は暫定で「筑駒縁日 Just Beat It 制作班」。各メンバーをハンドル名で出したいので、名前の出し方は相談したい。
- 問い合わせ先は置かない。
- 日本語と英語を切り替えられるようにする。

**参考にしたいサイト**
- deltarune.jp … シンプルさと最初のアニメーション（真っ黒 → ロゴが光ってきらめきながら出る → 副題 → 両脇から飾りが伸びる → ボタン）
- zenless.hoyoverse.com/ja-jp/main … 画面いっぱいの区画を「01〜06」の番号付きで並べる作り。キャラ紹介の「一覧から選ぶと大きく出る」形
- unbeatablegame.com … 勢いのある色・傾いた帯の見出し

**入れたい中身（上から）**
1. トップ: ロゴの登場アニメ（案: 各ステージの色の弾が拍に合わせて中央へ集まってロゴになり、光ってきらめく。両脇は花の代わりにステージの CG の切れ端や弾が伸びる）、一言のキャッチ、「無料ダウンロード（Windows / Mac）」、PV の再生
2. ゲームについて: 3 行くらいの紹介（曲に合わせて弾が来る弾幕避け・1〜2 人で遊べる）と特徴 4〜5 個。deltarune みたいにちょっと遊んだ一文を混ぜたい
3. ステージ: ゼンゼロのキャラ紹介風。10 ステージの一覧から選ぶと、背景がそのステージの CG に替わり、敵の絵と場所の名前がステージの色で出る（名前は場所の名前だけ。敵の名前は出さない。ゲーム内と同じ）
4. 映像: PV 第一弾
5. ダウンロード: 動く PC の条件・ファイルの大きさ・起動時に警告が出た時の開き方（Windows・Mac とも）
6. 遊び方: キーボード・コントローラーの操作、2 人で遊ぶ時
7. 制作: 制作班の名前とメンバー（ハンドル名と担当）
8. クレジット: フォント・素材の許諾（フォントの OFL の許諾文は必ず載せる。一覧はリポジトリの Docs/asset-credits.md）

**置き場所の案**: サイトは GitHub Pages（無料）、ゲーム本体は GitHub Releases（1 ファイル 2GB まで）。別の案があれば相談で。
